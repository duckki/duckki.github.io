<p class="page-intro">PL Rant is Duckki Oe’s notebook about programming languages and static analysis.</p>

I use this site to work through questions about ownership, reference semantics, mutability, type systems, and the proofs that make language features safe. The essays favor concrete examples and explicit reasoning over broad surveys.

You can find my code on [GitHub](https://github.com/duckki), connect on [LinkedIn](https://www.linkedin.com/in/duckki), subscribe through [RSS]({{ '/feed.xml' | relative_url }}), or [send me an email](mailto:{{ site.email }}).
